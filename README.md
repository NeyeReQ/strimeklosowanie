# RIFTROLL — League of Legends Randomizer

Polskojęzyczna, responsywna strona do losowania zestawu wyzwań w League of Legends.

## Funkcje
- Losowanie jednej z pięciu pozycji lub ustawienie jej ręcznie.
- Losowanie bohatera z pełnej puli Data Dragon.
- Generowanie struktury strony run: 4 runy ścieżki głównej, 2 runy dodatkowe oraz 3 statystyki.
- Losowanie sześciu przedmiotów z puli Summoner's Rift, w tym maksymalnie jednego przedmiotu z kategorii butów.
- Niezależne ponowne losowanie każdej sekcji oraz blokowanie wyników.
- Kopiowanie zestawu do schowka.
- Przeglądarka bazy bohaterów, przedmiotów i run z wyszukiwarką.

## Uruchomienie
To statyczna strona — nie wymaga Node.js, instalowania pakietów ani backendu. Otwórz index.html lub opublikuj repozytorium przez GitHub Pages.

## Dane i grafiki
Strona pobiera najnowszą dostępną wersję Riot Games Data Dragon przy uruchomieniu. Nazwy i dane są pobierane z lokalizacji pl_PL (z awaryjnym przejściem na en_US), a grafiki z oficjalnego CDN Riot Games.

Źródło: https://developer.riotgames.com/docs/lol

## GitHub Pages
W repozytorium wybierz **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
